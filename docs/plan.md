模块 2：硬性排雷过滤器 (进入估值计算前的检查)
功能描述：基于最近一份年报/滚动12个月(TTM)数据，自动标记触雷品种。
数据来源：合并cashflow, balancesheet, income。
实现细节：

利润含金量检查 (CFO/净利润)：

计算：经营性现金流净额TTM / 归母净利润TTM。计算该比值连续3年的平均值。

评级逻辑：

<0.5：🔴 红灯，建议直接排除，标记“利润质量严重可疑”。

0.5≤x<0.7：🟡 黄灯，核心预警，标记“利润含金量不足，需深度审查”。

0.7≤x<1.0：🔵 蓝灯，提示“现金流偏弱”。

≥1.0：🟢 健康。

设计：默认排雷线设为0.7，但允许用户自行调整。

商誉减值风险检查：

计算：商誉 / 净资产。

阈值：>30% 则标记为“商誉风险高悬”。对于该比值>50%且行业非轻资产服务业的，直接排雷。

资金占用风险检查：

计算：(其他应收款) / 净资产。

阈值：>20% 则高度警惕，可能关联方占用资金，标记“资产结构存疑”。

运营恶化检查：

计算：应收账款周转天数 和 存货周转天数 的3年变化趋势。

阈值：如果两者均连续大幅上升（例如3年累计升幅>30%），标记“营运能力持续恶化”。

模块 4：估值算子库 (核心计算逻辑)
功能1：改良版 DCF

计算流程：

自由现金流(TTM)：FCF = 净利润TTM + 折旧摊销TTM - 资本开支TTM - 营运资本增加TTM（所有数据可从现金流表简化计算）。
预测期：10年。
前5年增速：用户输入，或默认取近3年营收复合增速的60%与行业均值中较低者。
后5年增速：线性回归至永续增长率。
永续增长率：默认3%，等于长期通胀+GDP。
折现率(WACC)：用户可调，默认8%-10%，可用10年期国债收益率+风险溢价估算。
终值：第10年FCF * (1+3%) / (WACC-3%)。
输出：企业内在价值 = 未来10年FCF折现值 + 终值折现值，每股内在价值 = (企业价值 - 净债务) / 总股本。生成悲观、中性、乐观三条曲线。
功能2：ROE-PB 匹配框架

计算：

合理PB = (ROE_sustainable - g) / (r - g)。其中g为永续增长率(取3%)，r为股东要求回报率(取WACC或9%-10%)。

ROE_sustainable：取近5年扣非ROE中位数，与最新一期ROE较低者。

判断：(当前PB / 合理PB - 1) * 100%，负值越大越低谷。

功能3：席勒市盈率 (CAPE)

计算：

10年经通胀调整净利润均值：逐年计算归母净利润 * (今期CPI / 当期CPI)，然后取10年均值。若无CPI数据，可用名义值近似（需注意），或直接使用名义净利润但要求用户理解。

CAPE = 当前总市值 / 10年经调整净利润均值。

分位点：计算当前CAPE在其10年历史中的分位数。

功能4：股债性价比 (ERP)

计算：风险溢价 = (1 / 沪深300 PE(TTM)) - 10年期国债收益率。

展示：以“温度计”图表展示当前风险溢价在历史均值±2倍标准差的位置。此为市场整体估值信号，用于决定整体仓位。

功能5：PEG 估值

计算：PEG = PE(TTM) / (未来3年净利润复合增长率预测 * 100)。

增长率预测：取自券商一致预期（若Tushare无法获取，可用近3年自建预测模型，如线性外推再打8折作为保守预期）。

合理线：PEG < 0.8 可能低估。

功能6：股息与自由现金流回报率

股息率：近三年平均股息 / 股价，附上分红持续性检查（分红率<70%，且FCF覆盖倍数>1）。

FCF/EV 回报率：FCF TTM / 企业价值EV (市值+净债务)。该比率>5%即具吸引力。

模块 5：结果综合与展示仪表盘
对每只个股，最终展示一个综合卡片。

1. 估值综合评分 (百分制)

所有量化估值模型(如DCF折扣率、PB低估程度、PE分位数等)的结果，映射到0-100分区间。

按行业权重加权求和，得到最终评分。例如：85分，表明从多个维度看价格低于长期内在价值。

2. 安全边际仪表

核心展示：DCF得出内在价值区间(悲观/中性/乐观)，当前股价对应的折扣。如：“现价46元，对比中性内在价值68元，有32%安全边际。”

历史位置：一个垂直温度计，显示当前PE/PB/CAPE处于10年历史的分位数。

3. 长期回报拆解

自动计算：预期年化回报 = 股息率 + 可持续增长率 + 估值均值回归贡献。

估值均值回归贡献 = (未来合理PB/当前PB)^(1/5) -1，假设5年内估值回归到合理PB。
