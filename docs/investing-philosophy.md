# A股长期价值投资理念（FinAnalyzr）

## 1. 核心原则

1. 能力圈原则：只覆盖能理解商业模式与竞争格局的公司。
2. 护城河原则：关注品牌、成本、网络效应、转换成本、牌照等结构优势。
3. 现金流原则：自由现金流比会计利润更能反映长期价值。
4. 治理原则：管理层诚信、资本配置效率、股东回报政策同等重要。
5. 安全边际原则：内在价值与市场价格间必须保留缓冲区。
6. 长期纪律原则：容忍阶段性波动，反对频繁交易和情绪化决策。

## 2. 方法框架

1. 先定性：行业结构、竞争优势、商业模式可持续性。
2. 再定量：DCF、ROE-PB、相对估值（PE/PB/PCF/PEG）、CAPE、FCF/EV、SOTP、Graham 多模型交叉验证。
3. 后决策：结合质量评分与安全边际，输出低估/合理/高估分级。

## 3. 估值引擎口径

1. DCF：基于未来现金流折现，采用终值占比约束与情景区间输出。
2. ROE-PB：用可持续 ROE 与长期回报要求推导合理 PB，适配金融/稳健资产。
3. 相对估值：PE/PB/PCF/PEG 对标行业与历史分位，适合横向比较。
4. CAPE：对强周期行业使用跨周期盈利均值口径，降低单年利润噪声。
5. FCF/EV：用现金回报率衡量企业价值吸引力。
6. SOTP：对多业务结构公司做分部估值。
7. Graham：作为快速校验锚点，不单独用于最终决策。

## 4. 排雷与风险控制口径

1. ST/*ST：触发硬性阻断。
2. 上市年限：<5 年降置信度，<1 年更强惩罚。
3. 现金流质量：非金融行业采用 OCF/NI 分档预警与硬红旗。
4. 资产质量：商誉占比、其他应收占比分档预警。
5. 营运恶化：应收与存货周转天数 3 年累计上升超过阈值触发预警。
6. 分红可持续性：高分红支付率与现金覆盖弱触发预警。
7. 市场温度：股债利差温度计对综合评分做周期修正。

## 5. 风险与失效条件

1. 假设敏感：增长率、折现率微小变化可能显著影响结论。
2. 数据风险：财务口径不一致、一次性项目、会计估计调整会扭曲结果。
3. 周期风险：强周期行业在不同阶段同一估值倍数含义不同。
4. 治理风险：即使估值便宜，治理失效也可能导致价值陷阱。

## 6. 不适用范围

1. 短线择时和高频交易。
2. 题材驱动、纯情绪交易。
3. 自动化交易执行。

## 7. 使用建议

1. 把工具当作“决策辅助”，不是“决策替代”。
2. 对关键参数做乐观/中性/保守三情景推演。
3. 持续更新假设并复盘偏差来源。
